# Bundled Thai receipt fonts

The active receipt font is **Noto Sans Thai Looped**, with regular body text
(weight 400) and bold headings/results (weight 700). It provides familiar looped
Thai letterforms. Receipts are shaped by HarfBuzz and rendered by FreeType at the
printer's native pixel width; these files work offline on Windows and Linux.

- `NotoSansThaiLooped.ttf`: unchanged variable font from
  https://github.com/google/fonts/tree/main/ofl/notosansthailooped
- `OFL-NotoSansThaiLooped.txt`: its SIL Open Font License and copyright notice.
- `NotoSansThai.ttf` / `OFL.txt`: the previous receipt font retained separately.

The receipt font is bundled with the Pi package. No OS font installation is needed.
