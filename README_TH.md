# Leaf Lab — โปรแกรมวิเคราะห์ภาพใบพืช

เว็บภาษาไทยที่ทำงานบนเครื่อง Windows ใช้ชุดข้อมูล PlantVillage ในโฟลเดอร์นี้ พร้อมโมเดลที่ฝึกแล้ว รองรับภาพ JPG, PNG และ WebP ขนาดไม่เกิน 8 MB และ 25 ล้านพิกเซล

## เริ่มใช้งาน

1. ดับเบิลคลิก `start.bat` ในโฟลเดอร์เดียวกับไฟล์นี้
2. โปรแกรมจะเปิดเบราว์เซอร์ที่ **http://127.0.0.1:8765**
3. เลือกภาพหรือลากภาพมาวาง แล้วกด **วิเคราะห์ภาพ**
4. ดูผล 3 อันดับ พร้อมคะแนนโมเดล หรือกด **บันทึกผลวิเคราะห์** เพื่อดาวน์โหลด JSON

เปิดหน้าต่างโปรแกรมค้างไว้ขณะใช้งาน ปิดหน้าต่างหรือกด Ctrl+C เพื่อหยุดเซิร์ฟเวอร์ ถ้าโปรแกรมทำงานอยู่เบื้องหลัง ให้ดับเบิลคลิก `stop.bat` เพื่อหยุด เปิดครั้งถัดไปด้วย `start.bat` ได้เลย ไม่ต้องฝึกใหม่

ครั้งแรกบนเครื่องใหม่ต้องมี Python 3.11 ขึ้นไป และอินเทอร์เน็ตสำหรับติดตั้งไลบรารี หลังติดตั้งแล้วการเปิดเว็บ การวิเคราะห์ภาพ และการฝึกโมเดลทำงานออฟไลน์ ภาพไม่ถูกส่งไปบริการภายนอก แอปไม่เก็บภาพอัปโหลดถาวร

ถ้าเปิดหน้าเว็บไม่ขึ้น ให้รันใน PowerShell จากโฟลเดอร์นี้เพื่อดูข้อความผิดพลาด:

```powershell
.\.venv\Scripts\python.exe app.py --open-browser
```

## เมนูในโปรแกรม

- **วิเคราะห์ใบพืช:** อัปโหลดภาพหรือเลือกภาพตัวอย่าง แล้วดูผลทำนาย ภาพจากชุดข้อมูลจะมีป้ายบอกว่าใช้ฝึก ใช้ทดสอบ หรือไม่ได้อยู่ในชุดที่เลือก
- **สำรวจชุดข้อมูล:** เลือกกลุ่มพืช/อาการ เปิดดูภาพ และเลือกภาพเพื่อทดลองวิเคราะห์
- **โมเดลของฉัน:** ดูความแม่นยำ ผลแยก 38 กลุ่ม และฝึกใหม่โดยเลือกได้สูงสุด 150, 300 หรือ 600 ภาพต่อกลุ่ม

## ใช้เว็บแคมหรือกล้อง USB

1. เปิดหน้า **วิเคราะห์ใบพืช** แล้วเลือก **ใช้กล้อง**
2. กด **เปิดกล้อง** และเลือกอนุญาตเมื่อเบราว์เซอร์ถาม หากมีกล้องหลายตัว เลือกจากช่อง **กล้องที่ใช้**
3. จัดใบพืชหนึ่งใบให้อยู่เต็มกรอบกลางภาพ โดยใช้แสงสม่ำเสมอและพื้นหลังเรียบ
4. กด **วิเคราะห์ภาพจากกล้อง** เพื่อวิเคราะห์ครั้งเดียว หรือกด **เริ่มวิเคราะห์ต่อเนื่อง** เพื่ออัปเดตผลอัตโนมัติ
5. เลือกเว้นช่วง 2, 3 หรือ 5 วินาที ระบบจะรอผลภาพปัจจุบันก่อนจับภาพถัดไป จึงไม่มีคำขอซ้อนกัน
6. กด **หยุดวิเคราะห์ต่อเนื่อง** เพื่อหยุดประมวลผล หรือ **ปิดกล้อง** เพื่อหยุดใช้กล้องด้วย

ส่งเฉพาะภาพสี่เหลี่ยมในกรอบกลางไปวิเคราะห์บนเครื่อง พร้อมแสดงภาพที่ใช้จริงและเวลาจับภาพข้างผลทำนาย กรอบนี้เป็นพื้นที่จัดวางใบที่กำหนดไว้ ไม่ได้ขยับติดตามใบหรือระบุตำแหน่งโรคอัตโนมัติ โมเดลยังจำแนกภาพใบทีละใบตาม 38 กลุ่มเดิม

กล้องจะปิดเมื่อเปลี่ยนไปหน้าอื่นในโปรแกรม เปลี่ยนไปใช้ไฟล์ ออกจากแท็บ หรือปิดหน้าเว็บ กลับมาแล้วกดเปิดกล้องใหม่ ไม่มีการใช้ไมโครโฟนและไม่มีการบันทึกวิดีโอ

ใช้งานบนเครื่องที่รันแอป ผ่าน `http://127.0.0.1:8765` หรือ `http://localhost:8765` หากถูกปฏิเสธสิทธิ์ ให้เปิดสิทธิ์กล้องจากไอคอนข้างแถบที่อยู่ และตรวจ Windows Settings > Privacy & security > Camera หากกล้องถูกใช้งานอยู่ ให้ปิดโปรแกรมที่ใช้กล้องนั้นก่อน การนำไปเปิดจากอุปกรณ์อื่นยังต้องตั้งค่าเครือข่ายและ HTTPS เพิ่มเติม

ทดสอบกล้องจำลอง (ไม่เปิดกล้องจริง) หลังเปิดแอปไว้แล้ว:

```powershell
.\.venv\Scripts\python.exe tests/browser_camera.py
```

อ้างอิงพฤติกรรมการขอสิทธิ์และข้อกำหนดของเบราว์เซอร์: [MDN: getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

## โมเดลเริ่มต้นที่ให้มา

ใช้ Extra Trees กับคุณลักษณะสี พื้นผิว และขอบภาพ ประมวลผลด้วย CPU ไม่ต้องมี GPU เป็นโมเดลพื้นฐาน ไม่ใช่ deep learning

ผลการฝึกครั้งแรกด้วย seed 42 และเพดาน 300 ภาพฝึกต่อกลุ่ม:

| รายการ | ผล |
|---|---:|
| ภาพฝึก | 11,130 |
| ภาพทดสอบ | 3,569 |
| ทำนายอันดับแรกถูกต้อง | 82.94% |
| คำตอบจริงอยู่ใน 3 อันดับแรก | 94.87% |
| จำนวนกลุ่มพืช/อาการ | 38 |

ค่าล่าสุดหลังฝึกใหม่ดูได้ในหน้า **โมเดลของฉัน** และ `models/metrics.json`

แบ่งข้อมูลโดยจัดกลุ่มตามรหัสใบจาก `leaf_grouping/leaf-map.json` ก่อนสุ่มภาพ แล้วเลือกประมาณ 20% ของกลุ่มในแต่ละคลาสเป็นชุดทดสอบ กลุ่มที่มีรหัสกำกวมในคลาสเดียวกันถูกเชื่อมรวมก่อนแบ่ง ชื่อภาพที่ไม่มีข้อมูลรหัสใบใช้ชื่อที่ปรับรูปแบบแล้วเป็นกลุ่มสำรอง จึงยังยืนยันไม่ได้ว่าทุกกลุ่มสำรองเป็นคนละใบทางกายภาพ

ชุดทดสอบสุ่มสูงสุด 100 ภาพต่อกลุ่ม (หรือน้อยกว่านี้ตามขนาดการฝึก) ไม่ใช่ชุดทดสอบทางการของโครงการต้นฉบับ เก็บรายชื่อภาพและกลุ่มใบที่ใช้จริงไว้ใน `models/split_manifest.json` เพื่อให้ตรวจสอบซ้ำได้ ผลในตารางวัดจากชุดข้อมูล PlantVillage เท่านั้น ไม่ได้ยืนยันผลกับภาพถ่ายภาคสนาม

คะแนนต่อภาพเป็นคะแนนจากโมเดล ยังไม่ปรับเทียบเป็นโอกาสยืนยันโรค โมเดลเลือกจาก 38 กลุ่มที่รู้จักเสมอ แม้ส่งภาพที่ไม่ใช่ใบพืชหรือพืชชนิดอื่น ควรใช้เป็นเครื่องมือเรียนรู้และผลเบื้องต้น ไม่ใช่ข้อยืนยันโรค

## สำหรับผู้พัฒนา

ไฟล์โปรแกรมใหม่อยู่ด้านนอกโฟลเดอร์ชุดข้อมูลเดิม:

```text
start.bat                 เปิดโปรแกรมบน Windows
app.py                    เว็บและ API ภายในเครื่อง
train.py                  ฝึกโมเดลจากคำสั่ง
leaflab/dataset.py         อ่านชุดภาพและแบ่งกลุ่มใบ
leaflab/model.py           เตรียมภาพ ฝึก และทำนาย
templates/index.html      หน้าเว็บภาษาไทย
static/                   CSS, JavaScript และไอคอน
models/                   โมเดล ผลทดสอบ และรายชื่อภาพ
tests/                    ทดสอบ API และการใช้งานผ่านเบราว์เซอร์
PlantVillage-Dataset-master/raw/color/   ชุดข้อมูลเดิม
```

คำสั่งติดตั้งและรันเอง:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe train.py --samples-per-class 300
.\.venv\Scripts\python.exe app.py --open-browser
```

หากพอร์ต 8765 มีโปรแกรมอื่นใช้ ให้รัน `app.py --port 8766 --open-browser`

คำสั่งทดสอบ (ต้องมีชุดข้อมูลและโมเดลที่ฝึกแล้ว):

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

ทดสอบหน้าเว็บด้วย Microsoft Edge ที่ติดตั้งในเครื่อง โดยเปิดแอปไว้ก่อน:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe tests/browser_smoke.py
```

หากโปรแกรมปิดผิดปกติระหว่างฝึกและแจ้งว่ามีการฝึกอยู่ ให้ตรวจว่าไม่มีโปรแกรมกำลังฝึกแล้วจึงลบ `models/training.lock` ก่อนเปิดใหม่ อย่าเปิดไฟล์โมเดล joblib ที่ได้จากแหล่งที่ไม่เชื่อถือ

เว็บฟังเฉพาะ `127.0.0.1` และใช้ Waitress ไม่มีบัญชีผู้ใช้หรือบริการภายนอก ต้องเปิดจากเครื่องที่รันโปรแกรมเท่านั้น การป้องกัน POST ใช้ token ของแอปและตรวจ Host

เอกสารที่ใช้อ้างอิงในการพัฒนา: [Flask file uploads](https://flask.palletsprojects.com/en/stable/patterns/fileuploads/), [ExtraTreesClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.ExtraTreesClassifier.html)

ข้อมูลภาพและแหล่งอ้างอิงงานวิจัยดูได้ใน `PlantVillage-Dataset-master/README.md` โปรแกรมนี้ไม่ได้แก้ไขภาพหรือสคริปต์เดิมของชุดข้อมูล
